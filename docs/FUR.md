# 0.4 / 毛並みの実装

体表の模様に加えて、輪郭から実際に伸びる毛束のジオメトリを追加しました。下毛と差し毛の2層を重ね、短毛5種と長毛5種を別の毛量・毛丈で生成します。毛束の形・アルファ・毛流れは独自制作です。顔の毛色はCC BY素材から改変した顔テクスチャをサンプリングします。出典は [FACE.md](FACE.md)。

## 密度と毛流れ

| | 短毛 | 長毛 |
| --- | --- | --- |
| 下毛の根元サンプル | 2,400 | 3,800 |
| 差し毛の根元サンプル | 3,200 | 5,200 |
| 胴の差し毛の基準長 | 11 mm | 28 mm |
| 胸の基準長 | 15 mm | 40 mm |
| 頬の基準長 | 7 mm | 14 mm |
| 尾の基準長 | 19 mm | 48 mm |
| 口元・耳の基準長 | 3.5 mm | 3.5 mm |

目・鼻・口の周りでは長い毛を除きます。このため、書き出す体表の毛束数はサンプル数より少なくなります。モデルごとの実数はGLBの `extras.fur.layers` に保存しています。長さには0.72～1.25倍のばらつきを付け、下毛は差し毛の基準長の0.52倍にします。尾の先と足先も短くします。

根元は体表の三角形の面積に比例して配置し、顔・胸・尾を重点的に増やします。背中から尾へ、胸から下へ、頬から外へ流す方向場に従い、各毛束を4段の湾曲したリボンとして生成。1束6三角形で、4種類のアルファテクスチャがそれぞれ52本の先細りした線を含みます。これは独立して物理計算する52本の毛ではありません。

## 柔らかな見え方

- 半透明の `BLEND` を使用し、細い毛が縮小されたときに板の形へ固まる現象を抑えます。Cesiumの標準の透過描画を使います。
- 毛束の鋭い面法線ではなく体表の滑らかな法線で照明を計算し、毛束ごとに白黒が分かれる現象を抑えます。毛先は根元より少し明るくします。
- `fur-light.mjs` が視線に対して浅い角度の毛へ控えめな明るさを加えます。物理的な毛内部の散乱計算ではありません。
- GLBには任意拡張 `KHR_materials_sheen` も記録します。対応ビューアー向けであり、ゲーム内のCesiumは上記の独自シェーダーによる近似です。
- 耳の縁と内側にも短い毛束を追加。頬・頭の丸み、瞳孔と光の映り込みを調整し、表情を柔らかくしました。

仕様確認に使った一次資料： [Khronos / KHR_materials_sheen](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_sheen/README.md)、[Cesium 1.127 / CustomShader Guide](https://github.com/CesiumGS/cesium/blob/1.127/Documentation/CustomShaderGuide/README.md)。

## 動き・距離による描画量

毛束の根元は体表の3頂点からジョイントの影響を補間し、最大4つのウェイトで同じ26関節のスキンへ結びつけます。頬、胸、脚、尾の動きに追従します。耳の毛も頭部の体表から生成し、左右の耳のウェイトに追従します。まぶたのモーフによる毛根の移動は実装していません。独立した風・重力・毛同士の接触計算は行いません。

操作中の猫は常に2層を表示。周囲の猫はプレイヤーから12 m以遠（高画質は18 m）で差し毛、28 m以遠で下毛を省きます。遠くでも体表の毛の色・法線テクスチャは残ります。18 m以遠の猫の関節更新は毎秒最大10回へ抑え、位置と歩行周期の進行は続けます。

測定は `FurReviewTest#fluffyCloseup` がAndroidのタッチで長毛のラグドールを選び、カメラを近づけ、読み込みを待ってから行います。直近180回の描画間隔の平均からfpsを算出し、95パーセンタイルも保存します。FPSはエミュレーターの特定場面の観測値です。実機の発熱・バッテリー・長時間性能は別途検証が必要です。

再生成: `python3 tools/build_cats.py`。単体調整は `--breed ragdoll`。検査: `python3 tools/verify_models.py`。毛束数、部位別の根元数、長さ、半透明マテリアル、法線・面方向、スキンウェイト、全アニメーションの足支点とループを実ファイルで検査します。

この方式はモバイル用の毛束による表現です。実写と同じ密度の個々の毛、物理的な散乱、筋肉・皮膚の精密な変形を再現した完成モデルではありません。
