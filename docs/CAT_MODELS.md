# TOKYO-CAT / 猫モデル 0.1.0-dev

ユーザー指定動画を観察参考として独自制作した、スキン付きGLB 2.0の10モデルです。**写実品質は未達の開発用モデル**です。動画の猫をそのままスキャンしたものではなく、動画画像・音声・フレーム由来のテクスチャは含みません。

参考：[ネコの生態【サクっと解説】](https://www.youtube.com/watch?v=Jxv0e1VXSR0)。観察メモは `sources/cat-video-reference.json`。

## 技術情報

- 単位：メートル。ローカル軸：+Xが正面、+Yが上。
- 22ジョイントのスキン。連続した体表、目、耳、鼻、ひげ、毛色、長毛の輪郭と近似的な接地表現。
- Idle / Walk / Trot / Greet の独立したサンプルアニメーションクリップを格納。
- ゲーム内ではサンプルクリップとは別に、移動距離に同期した歩行周期・二関節IK、停止時の接地、座位、頭と尾の動きを制御。
- 外部テクスチャ不要。マテリアルとテクスチャはGLB内部に格納。
- `manifest.json` にモデルごとのSHA-256、ファイルサイズ、ノード数を収録。
- BlenderなどのglTF 2.0対応ツールでインポート可能な形式です。検証は独自のファイル検査とAndroid上のCesium描画で実施し、Blender上の検証は行っていません。

Cesiumで使用する場合、`upAxis: Cesium.Axis.Y` と `forwardAxis: Cesium.Axis.X` を指定しています。軸の既定値に任せると、正面と進行方向がずれる場合があります。

## 品質と制作範囲

猫種ごとに脚の長さ、体格、耳や毛色を変えていますが、個体の正確な解剖学的モデルではありません。実写同等の毛並み、自然な顔、品種差、足の滑り抑制、関節変形、リアルな歩様にはさらに改良が必要です。動画からの写真測量やモーションキャプチャは行っていません。

生成コードはAndroidプロジェクトの `tools/build_cats.py` と `tools/skin_surface.py`、検査は `tools/verify_models.py`。公開配布用の独自コード・モデルのライセンスはまだ設定していません。
