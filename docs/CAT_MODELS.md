# TOKYO-CAT / 猫モデル 0.3.0-dev

ユーザー指定動画とフリー素材を観察参考に独自制作した、スキン付きGLB 2.0の10モデルです。**写実品質を目指して改良中の開発用モデル**です。映像からのスキャンやモーションキャプチャではありません。参照画像をモデルに投影したテクスチャも含みません。

指定動画：[ネコの生態【サクっと解説】](https://www.youtube.com/watch?v=Jxv0e1VXSR0)。今回追加した無料の参照元・作者・ライセンス・利用範囲は [cat-reference/README.md](sources/cat-reference/README.md) にまとめています。

## 0.3の変更

10種を密な下毛・差し毛の2層へ置き換えました。毛束を体表面積に比例して分布させ、頬・胸・尾に重点配置。毛先が透ける曲面のリボンと部位別の長さ・流れで柔らかい輪郭を作ります。短毛は最大5,600、長毛は最大9,000の体表の毛束に、左右各240の耳の毛束を追加。目・鼻を避けた実数は各GLBのメタデータを参照してください。

頬と頭の丸みを増やし、瞳孔とキャッチライトを調整しました。耳は内側の露出を小さくして縁に毛を追加しています。ゲームでは距離に応じた毛の描画省略と、遠方の関節更新の削減を実施します。[毛の詳しい仕様](FUR.md)。

## 0.2で実装した基礎

- **形状**：短い口元、頬、鼻筋、眼窩、肩・胸・背中の輪郭、細い脚と足先を再制作。耳は曲面、裏面、縁を持ち、平たい三角形だけの構造から変更。
- **顔**：眼窩に収まる目、虹彩の放射状模様、縦長の瞳孔、三角形の鼻と口の線、先細りの曲線によるひげ。目と耳を独立したノードとして動かします。
- **毛**：独自生成した毛の細かな色・法線テクスチャを体表に追加。0.2では短毛700枚／長毛1,600枚の毛カードを使用し、0.3で2層の毛束へ置換。柄は脚や尾のリング、頬、背中、白い口元、ラグドールのポイントと明るい顔の部分を分けました。
- **脚運び**：前脚と後脚の曲がる向きを修正。停止時は脚を伸ばし、移動時には体を少し低くして接地／遊脚を計算。移動速度と歩幅の不整合による足の滑りを修正。足を離す・着く瞬間の水平方向の速度をつなげています。
- **表情・姿勢**：まばたき、呼吸、耳、肩、5節の尾を追加。座る途中も後ろ足の支点を地面へ解くIKを使用。
- **再生の一致**：ゲームとGLBのサンプルアニメーションを同じ `cat-motion.mjs` から生成。別々の脚振りコードを廃止し、Sitクリップを追加しました。

## 技術仕様

- メートル単位。+Xが正面、+Yが上。体表・毛は24ジョイントのスキン。
- 体表は約28,000～37,000頂点。GLB内にマテリアル、色、法線、毛、虹彩のテクスチャを格納。
- Idle / Walk / Trot / Greet / Sitの5クリップ。各61サンプル、末尾は始端と一致させています。
- 毛束は半透明のBLEND。接地の柔らかい影はデカールによる近似表現。
- 歩行周期は移動距離 ÷ 猫種の脚の長さに応じた周期距離。通常歩行の接地率0.66、速歩0.52へ補間。定速の接地では足の後退量が前進距離を打ち消します。
- 始動・停止はブレンド。旋回、急加減速、段差、斜面については、足の固定点を保存する本格的な全身接地ソルバーではありません。
- `manifest.json` にモデル別SHA-256、サイズ、ノード・三角形数を記録。

## 再生成と検証

Node.js、`tools/model-requirements.txt` のPython依存が必要です。

```bash
python3 tools/build_cats.py
python3 tools/verify_models.py
node --test tests/*.test.mjs
```

Nodeのパスは `TOKYO_CAT_NODE` で指定可能です。`tools/export_cat_motion.mjs` が共有の姿勢計算をサンプリングし、Pythonが形状・スキン・クリップをGLBへ格納します。検査ではバッファ、法線、スキン、毛のバインド、クリップの連続性に加え、実際に書き出した全クリップの足支点が床より下に落ちないこと、静止・座位では接地することを確認します。

Cesiumでは `upAxis: Cesium.Axis.Y`、`forwardAxis: Cesium.Axis.X` を指定。Android上で各モデルを読み込んで操作・表示を検証します。Blender上での検証は未実施です。

## 残る品質上の制約

形状・柄・動きは参照をもとにした手続き的な近似です。品種の精密な骨格、筋肉・肩甲骨の変形、独立した毛の物理挙動、まぶたの皮膚変形、実測された歩様、走る際のギャロップや背骨の大きな伸縮は再現できていません。Muybridgeの連続写真は観察しましたが、そのギャロップを実測再構成したとは扱いません。速度を上げた際は速歩の近似です。

猫モデルの形状、毛、瞳のテクスチャは独自制作です。参照した無料モデルのファイルをコピーしたものではありません。独自コード・モデルの外部利用ライセンスは未設定です。
