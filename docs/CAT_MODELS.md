# TOKYO-CAT / 猫モデル 0.4.0-dev

独自の体・毛・移動と、CC BY 4.0の顔を組み合わせたスキン付きGLB 2.0の10モデルです。写実品質を目指して改良中です。映像からのスキャンやモーションキャプチャではありません。

顔はBicolor Cat / kenchoo、原作Fripouille / guillaume bolisを改変。頭と目を細分化し、色、リグ、毛、まぶたの動きを変更しました。顔の色画像は内蔵imagegenで細部を補整しています。[制作・出典](FACE.md)。作者名・CC BY 4.0・変更内容はGLBのメタデータ、アプリ内クレジット、同梱ATTRIBUTION.mdにも記録しています。

## 技術仕様

- メートル単位。+Xが正面、+Yが上。体・顔・毛は26ジョイントのスキン。
- 顔30,817頂点、眼球3,077頂点。胴体は連続した暗黙曲面から生成。モデル別の規模は [fur-model-stats.json](verification/fur-model-stats.json)。
- GLB内に色、法線、毛のアルファテクスチャと全バッファを格納。外部の画像取得なしで表示可能です。
- Idle / Walk / Trot / Greet / Sit / Blinkの6クリップ。各61サンプル。Blinkは顔と眼球のモーフウェイト、残る5本はゲームと共通の姿勢計算です。
- 下毛と差し毛の2層。短毛5種、長毛5種。目と鼻を避け、顔の細部が隠れない短い毛と、胸・尾の長い毛を分けます。[毛の仕様](FUR.md)。
- モデルの歩行周期は移動距離に対応。通常歩行の接地率0.66、速歩0.52へ補間。定速では接地足の後退量が前進距離を打ち消します。急な旋回・加減速・斜面に対する全身接地ソルバーではありません。
- 接地の影は半透明デカール、角膜と毛の照明はモバイル向け近似。毛は独立した物理シミュレーションではありません。
- `manifest.json` にSHA-256、サイズ、ノード・三角形数を記録。

## 再生成と検証

Node.js、`tools/model-requirements.txt` のPython依存が必要です。通常の生成は同梱の顔キャッシュを使用し、Blenderを必要としません。元データからの抽出手順は [素材README](../tools/assets/cat-face/README.md)。Nodeのパスは `TOKYO_CAT_NODE` で指定できます。

```bash
python3 tools/build_cats.py
python3 tools/verify_models.py
node --test tests/*.test.mjs
```

検査はバッファ範囲、ハッシュ、有限値、法線、スキン、毛、顔のモーフと6クリップのループを対象にします。移動・姿勢5クリップの全61サンプルで足の支点を合成し、床より下に落ちないことを確認します。顔のみのBlinkは接地検査の対象外です。

Cesiumでは `upAxis: Cesium.Axis.Y`、`forwardAxis: Cesium.Axis.X` を指定します。GLBのBlinkと手続き的なIKを併用する際のCesium 1.127への対応は [FACE.md](FACE.md) に記録しています。
