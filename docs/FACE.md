# 0.4 / 顔の形状・質感

実写に近づけるため、0.3の単純な顔パーツを、まぶた・眼窩・頬・鼻・口元・耳の内側がつながる顔メッシュに置き換えました。実写相当の完成品質という判定ではなく、実際にアプリへ組み込んだ改良の記録です。

## 制作元

**Bicolor Cat / kenchoo**、原作 **3d modelling my cat: Fripouille / guillaume bolis** の顔と目を改変して使用しています。両作者の公開メタデータとGLB内の出典を確認し、**CC BY 4.0**の作者名、配布ページ、ライセンス、変更内容をアプリ内・APK・モデルZIPへ収録しました。元の胴体・リグ・移動アニメーションは採用していません。

- [Fripouille](https://sketchfab.com/3d-models/3d-modelling-my-cat-fripouille-0ab14bf98e754f8d90fe1bf1c84ca66c)

指定されたYouTube動画と、以前に記録した猫の写真・連続写真は観察資料です。動画の個体を写真測量で復元したモデルではありません。

## 実装

- 元メッシュをBlender 5.1.1で細分化し、顔と眼球を抽出。UVの継ぎ目を保持した顔30,817頂点、目3,077頂点を使用します。
- 元の顔の色画像をもとに、内蔵imagegenで毛・鼻・口元の細部を補整しました。`detailed-albedo.png` は生成したマテリアル画像であり、実写写真やゲームのスクリーンショットではありません。[使用プロンプト](sources/cat-face/texture-prompt.txt)も保存しています。
- 顔は補整した色テクスチャと元の法線テクスチャを使用。目は元の色画像を使い、ラグドールの虹彩を青系へ調整します。猫種ごとに毛色、頭幅、折れ耳を調整しました。全品種の実測形状を採用したわけではありません。
- 頭・左右の耳を26関節の既存リグへバインド。頭部の毛束は顔の色をサンプリングし、短い口元、頬、耳の毛を分けます。体と尾は従来の下毛・差し毛を維持しています。
- 元モデルのまぶた・眼球の変形を使った `Blink` を追加。5.7秒の周期中で閉じ、短く保持して開きます。毛束は関節に追従しますが、個々の毛の物理運動やまぶたのモーフには追従しません。目の周りでは長い毛を除いています。
- 角膜は低い粗さと空・地面の近似反射、視線角度による反射量の変化で表現。近くの建物の正確な映り込み、多重散乱、屈折を実時間で計算する方式ではありません。GLBの任意拡張 `KHR_materials_ior` とゲーム独自のシェーダーを併用します。
- 曲線のひげは根元から先へ細くなります。FXAAを有効にしましたが、細いひげは遠距離や低解像度で途切れて見えることがあります。

## まばたきと歩行の同時再生

Cesium 1.127の `Model.update` は、`ModelNode.matrix` を直接設定すると、自動アニメーションの更新を省略します。ゲームのIK制御と顔のモーフを両立させるため、関節行列を設定する前に `activeAnimations.update(scene.frameState)` を呼びます。

この部分は固定したCesiumバージョンの内部APIに依存します。エンジン更新時には、歩行と顔のモーフの同時再生を再検証してください。[Cesiumの実装](https://github.com/CesiumGS/cesium/blob/1.127/packages/engine/Source/Scene/Model/Model.js)。Androidの `FaceReviewTest` で進行と表示を確認しています。

## 顔の撮影

撮影モードの「顔をアップ / Face close-up」で頭部を中心とした近接視点へ切り替わります。「全身に戻す / Full body」で元の距離と傾きを復元します。猫を囲む方向へドラッグでき、距離、座位、シャッター、アルバム保存も利用できます。撮影モードへ入り直すと全身表示へ戻ります。

[Android上の正面・横顔・まばたき](verification/cat-review.md)で実際の見え方を確認できます。顔と首の色のつながり、目の光学表現、品種差、独立した毛の密度・影などには改良の余地があり、実写と見分けがつかない水準には到達していません。
